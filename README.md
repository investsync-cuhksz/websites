# InvestSync Website

Rebuild of the InvestSync club website (Next.js + Tailwind, JavaScript).
Plan and decisions: see `docs/InvestSync Website.pdf`.

## Run locally
npm install
npm run dev   → http://localhost:3000

## Working together
- Never push to `main`. Make a branch (`feature/navbar`), push it, open a Pull Request.
- Pull `main` before starting new work.
